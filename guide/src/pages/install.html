This page starts Beer Menu for the first time on a computer that already has Docker with Compose installed. You type a few commands in a terminal; after that, everything is done in the browser.

Start Beer Menu for the first time

  1. Get the Beer Menu files: either download them from the Beer Menu project page (Code, then Download ZIP) and unzip them, or copy them with git: 
    git clone https://github.com/helmnet/beer-menu.git
  2. Open a terminal in the Beer Menu folder. If you downloaded the ZIP, the folder is named "beer-menu-main" instead. 
    cd beer-menu
  3. Choose where Beer Menu keeps its data. It uses a folder named "data" inside the Beer Menu folder, and runs as your own user so it can write there. Create the folder and set the user: 
    export PUID=$(id -u) PGID=$(id -g)
mkdir -p data
  4. Download Beer Menu and start it: 
    docker compose pull
docker compose up -d
  5. For the admin app, open http://localhost:8080/ in a browser on the same computer.
  6. For the TV display, open http://localhost:8080/display. It shows an empty tap until you put a keg on it.

Beer Menu keeps running in the background and starts again after a restart. Keep the "data" folder safe: it holds all your beers, kegs and settings.
